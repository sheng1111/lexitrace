# Chrome Web Store Listing Draft

## Name

LexiTrace 詞跡

## Short Description

輕量查詞與隱形複習插件

## Detailed Description

LexiTrace 詞跡 helps you read English web pages while quietly building vocabulary memory.

Select an English word or short phrase on any page to see a compact lookup popup with Traditional Chinese meaning, English hint, source sentence, and save actions. Saved words are stored locally, highlighted when they appear again, and reviewed through a recall-first flow so you practice remembering before seeing the answer.

詞跡不是整頁翻譯工具，也不是厚重的背單字 App。它適合需要閱讀英文文件、技術文章、GitHub issue、產品公告或職場英文內容的人。目標是在不打斷閱讀的情況下，把查詞紀錄、重複曝光和輕量複習藏進日常工作流程。

Key features:

- Contextual lookup for selected English words and phrases
- Traditional Chinese meanings and English hints
- Manual meaning correction
- Local-first vocabulary history
- Saved-word highlights on web pages
- Recall-first review before revealing saved meanings
- Lightweight due-review prompt when saved words appear again
- TOEIC and workplace relevance badges
- Optional Google Sheet sync for user-owned backup
- JSON export

Lookup sources include ECDICT, Free Dictionary API, Wiktapi / Wiktionary, Datamuse, MyMemory, and a small local fallback dictionary. An experimental unofficial Google Translate provider can be enabled manually for self-use builds.

Privacy-oriented by default:

- Vocabulary stays local unless Google Sheet sync is enabled.
- The extension does not upload full page contents.
- External lookup providers receive only the selected word or short phrase.
- No API secret is bundled into the extension.
