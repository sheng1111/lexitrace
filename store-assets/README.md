# LexiTrace Store Assets

This folder collects Chrome Web Store preparation material for LexiTrace 詞跡.

Contents:

- `chrome-web-store-listing.md`: copy-ready listing text.
- `privacy-practices.md`: privacy disclosure draft for Chrome Web Store.
- `oauth-setup.md`: Google OAuth notes for development and release.
- `demo-pages/`: local static pages used to produce screenshots.
- `screenshots/`: generated Chrome Web Store screenshot candidates.

Recommended screenshots:

1. `01-lookup-popup.png`: contextual lookup while reading.
2. `02-invisible-review.png`: passive recall prompt and saved word highlights.
3. `03-settings.png`: settings, sync, and experimental provider controls.

Chrome Web Store usually accepts 1280x800 or 640x400 screenshots. The generated screenshots are intended as a starting point; replace them with real browser screenshots after loading the packaged extension if you want a fully authentic listing.
